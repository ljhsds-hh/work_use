# 小叮 XiaoDing

Windows 10 / 11 上的轻量待办提醒工具。常驻托盘，不打扰日常操作，但该提醒的时候会把事情摆到你面前。

- 单文件程序，约 180 KB，不需要安装运行时
- 纯本地运行，任务数据全部保存在本机，没有任何网络请求
- 不需要管理员权限，不使用 MSIX 打包

## 提醒形态

| 形态 | 行为 |
| --- | --- |
| 右下角卡片 | 弹出在屏幕右下角，不抢焦点，可以继续手头工作。按钮为「已完成 / 延后 5 分钟 / 延后 10 分钟 / 自定义」 |
| 全屏遮罩 | 整屏盖一层蒙布或自定义背景图，提示卡片仍在右下角。没有关闭按钮，只能完成或延后 |

两个细节：

- 卡片右上角的关闭按钮按误操作处理，等同「延后 5 分钟」。任务只要没点「已完成」就会一直循环提醒。
- 全屏遮罩同一时间只呈现一个，多个任务同时到期时按顺序排队，处理完一个自动弹下一个。

## 快速添加

任意界面按 `Ctrl+Alt+N` 唤起输入条，一行写完回车即存，支持简单时间识别：

| 输入 | 解析结果 |
| --- | --- |
| `明天9点 交周报` | 标题「交周报」，明天 09:00 |
| `周五下午3点半 开会` | 本周五 15:30 |
| `12月5日 还信用卡` | 12-05 09:00 |
| `9:30 晨会` | 今天 09:30，已过则明天 |
| `交周报` | 默认 1 小时后 |
| `明天9点 交周报 #工作` | 同时归入「工作」分组 |

输入时下方会实时显示解析结果，识别不对可以直接看出来。

## 界面

全应用统一使用系统微软雅黑 UI（楷体笔画过细，小字号会断裂发虚），纸感暖白配墨绿，支持浅色与深色两套主题，侧栏底部可一键切换。

- 主窗左侧是导航：视图（今天 / 逾期 / 全部 / 已完成）与分组两层筛选分开，各带数量
- 右侧任务列表为自绘：分组标题吸顶、行内标签展示分组与提醒方式、置顶行带底色与 ★
- 点击行左侧圆圈直接完成任务，双击整行进入编辑，右键可置顶 / 编辑 / 删除
- 列表为空时显示引导页，带快捷键提示
- 编辑窗、设置窗全部使用自绘控件：圆角输入框、日期月历、时间选择、胶囊选项、自绘滑块，不出现系统控件边框
- 提醒卡片左侧有品牌竖线，逾期时间用赭红；按钮分主次

设计稿见 [Docs/ui-design-preview.html](Docs/ui-design-preview.html)，浏览器打开可切换深浅色查看。

## 功能

- 任务标题、备注、分组
- 到期时间、提前 N 分钟提醒
- 重复规则：不重复 / 每天 / 每周 / 工作日 / 自定义星期 / 每月某日 / 每 N 天
- 分组筛选，按分组首次出现顺序成组展示，组内按提醒时间排序
- 视图切换：全部 / 今天 / 逾期 / 已完成，可叠加分组与关键字搜索
- 点击圆圈快速完成，重复任务自动推进到下一次
- 任务置顶：右键菜单置顶后带 ★ 排在最前，不随分组和时间沉底
- 清理已完成：一键删除累积的已完成任务，带确认提示
- 暂停全部提醒、开机自启（默认关闭）
- 睡眠唤醒、解锁、系统时间变更后自动补扫，错过的提醒会标记为「已错过」
- 全屏遮罩暗度可调，支持自定义背景图

## 提醒队列

全屏提醒优先，同一时刻只显示一个；卡片提醒串行展示，处理完自动弹下一张，不会层层堆叠遮挡。

## 运行

运行 `Code\publish\XiaoDing.exe`（产物不入库，先按下节构建一次）。

关闭主窗口只会隐藏到托盘，双击托盘图标可以重新打开。退出请用托盘右键菜单里的「退出」。

全局快捷键 `Ctrl+Alt+N` 可在任意界面唤起快速添加。

## 构建

需要 .NET SDK 8 或更高版本，目标框架 `net472`（Windows 10 1803 及以上、Windows 11 均自带该运行时）。

```powershell
pwsh -File .\Code\build.ps1
```

产物输出到 `Code\publish\XiaoDing.exe`。

运行测试（零依赖控制台测试，覆盖时间解析与重复规则，退出码非 0 即失败）：

```powershell
dotnet run --project .\Code\tests\XiaoDing.Tests -c Release
```

应用图标为多尺寸 ICO（16–256），由脚本生成后随程序集内嵌，托盘与窗口按 DPI 自动取用：

```powershell
pwsh -File .\Code\scripts\gen-icon.ps1
```

## 数据与日志

| 内容 | 位置 |
| --- | --- |
| 任务数据 | `%APPDATA%\XiaoDing\tasks.json` |
| 应用设置 | `%APPDATA%\XiaoDing\settings.json` |
| 全屏背景图 | `%APPDATA%\XiaoDing\overlay.png` |
| 日志 | `%APPDATA%\XiaoDing\logs\xiaoding-YYYYMMDD.log` |

- 任务写入采用「临时文件 + 替换」，避免产生半截文件；文件损坏时会自动隔离为 `.corrupt-时间戳.json` 并回退为空列表。
- 日志按天分文件，单文件上限 1 MB，保留 7 天，只记录事件名，不写入任务内容。

## 实现要点

- 提醒窗口基于 `UpdateLayeredWindow` 实现逐像素透明，圆角与柔和阴影没有任何锯齿。
- 调度采用 15 秒心跳扫描全部任务，而不是给每条任务挂定时器，任务数量增长时不会产生计时漂移或句柄泄漏。
- 时间统一以 UTC 存储，展示时转换为本地时间；重复规则按本地墙上时间推进，跨夏令时不会偏移。
