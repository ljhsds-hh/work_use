落地说明

能直接做：配色、字体层级、圆角、按钮分级、卡片与遮罩重绘、空状态、编辑窗分区、分组侧栏 —— 这些都用现有自绘能力实现，没有新增依赖。

需要改造：主窗列表要从 ListView 换成自绘滚动面板，才能做行内标签和分组吸顶；预计新增 300–500 行绘制代码，性能仍是本地绘制，开销可控。

不建议做：毛玻璃模糊（需要 DWM 调用，Win10 老版本效果不一致）、Web 字体（WinForms 依赖系统字体，落地用系统自带字体）。

字体：全应用统一 微软雅黑 UI。楷体等书法字体笔画过细，9-11pt 小字号下会断裂发虚；微软雅黑 UI 笔画等宽、专为界面小字优化，Win10/11 自带。数字 Segoe UI。均为系统可用，不额外打包。
