## 1 总体概述

### 1.1 产品定位

轻量待办提醒工具，常驻系统托盘，不打扰日常操作；到点把待办摆到用户面前。整个软件只做"提醒我有任务"这一件事：**无网络请求、无声音、无广告、无统计报表**。

### 1.2 核心约束

1. **纯本地**：任务与设置全部保存在本机 `%APPDATA%\XiaoDing\`，全程零网络请求；
2. **免安装**：单文件 exe，不申请管理员权限，不使用 MSIX 打包；
3. **轻量**：常驻内存与 CPU 占用保持低水平；调度采用固定心跳扫描，不为每条任务挂定时器；
4. **单实例**：重复启动时新实例退出并唤起已有实例主窗口；
5. **提醒必达**：只要任务未被标记完成，提醒就持续循环；应用未运行期间到期的任务，重启后补提醒并标记「已错过」。

### 1.3 术语

1. **任务（Task）**：一条待办，含内容、备注、分组、到期时间、提前提醒量、重复规则、提醒形态、启用状态；
2. **提醒形态（ReminderStyle）**：`卡片`（右下角小窗）或 `全屏遮罩`；
3. **触发时刻（FireUtc）**：已延后取延后时间，否则取「到期时间 − 提前提醒量」；
4. **收尾**：完成 / 延后（5 / 10 / 自定义分钟数）二者之一。未收尾的提醒会继续循环。

## 2 任务模型

### 2.1 任务字段

| 字段 | 必填 | 说明 |
| ---- | ---- | ---- |
| 任务内容 | 是 | 最长 120 字；为空不允许保存 |
| 备注 | 否 | 最长 500 字 |
| 分组 | 否 | 最长 20 字；空分组在列表归入「默认」 |
| 到期时间 | 是 | 统一以 UTC 存储，展示转本地时间 |
| 提前提醒 | 否 | 0–720 分钟；0 表示到点提醒 |
| 重复规则 | 否 | 不重复 / 每天 / 每周 / 工作日 / 自定义星期 / 每月某日 / 每 N 天 |
| 提醒形态 | 是 | 右下角卡片 / 全屏遮罩 |
| 启用 | 是 | 停用任务不参与调度 |

### 2.2 重复规则推进

- 按**本地墙上时间**推进周期（跨夏令时不偏移），推进结果须晚于当前时刻；
- 每月某日遇小月自动取月末（如 1 月 31 日 → 2 月 28/29 日）；
- 重复任务点「完成」时不结案，而是推进到下一次并重置提醒状态；
- 仅当**时间 / 重复规则 / 提前量**发生变化时才重新武装任务；只改备注或分组不得让已完成任务复活。

## 3 提醒机制

### 3.1 调度

- 15 秒固定心跳扫描全部任务，触发条件：`触发时刻 ≤ 当前时刻` 且本次触发未被标记、任务未完成；
- 睡眠唤醒、会话解锁、系统时间变更时立即补扫一次；系统事件回调统一切回 UI 线程执行，避免与心跳并发；
- 到期超过 1 分钟才触发的标记「已错过」，界面用赭色强调。

### 3.2 两种提醒形态

| 形态 | 行为 |
| ---- | ---- |
| 右下角卡片 | 屏幕右下角滑入，不抢焦点；按钮：已完成 / 延后 5 分钟 / 延后 10 分钟 / 自定义；右上角关闭按钮等同「延后 5 分钟」 |
| 全屏遮罩 | 主屏整屏蒙布或自定义背景图，提示卡片仍在右下角；无关闭出口，只能完成或延后；同一时刻仅呈现一个，多个到期按顺序排队 |

补充规则：

1. 卡片与遮罩共用同一套卡片外观（同一绘制组件），仅关闭按钮有无不同；
2. 提醒串行展示，不堆叠遮挡；处理完一个自动弹下一个；
3. 用户以 Alt+F4 等方式关闭卡片窗口时按误操作处理（等同延后 5 分钟），不得静默丢失提醒；
4. 全屏遮罩在系统关机 / 注销 / 任务管理器结束时放行关闭，不得阻塞系统；
5. 排队中尚未弹出的提醒不得记为「已提醒」，退出重启后仍应补提醒；
6. 已完成 / 已改期的任务，其队列中残留的旧触发作废。

### 3.3 遮罩背景与暗度

- 支持上传自定义背景图（PNG/JPG/BMP/GIF），按屏幕比例铺满后叠加暗度；
- 暗度 0–100% 可调，保存后生效；背景图的增删改在点「保存」前不落盘，点「取消」不产生任何改动。

## 4 快速添加

全局快捷键 `Ctrl+Alt+N` 唤起输入条，一行写完回车即存，实时预览解析结果。

| 输入 | 解析结果 |
| ---- | ---- |
| `明天9点 交周报` | 标题「交周报」，明天 09:00 |
| `周五下午3点半 开会` | 本周五 15:30 |
| `12月5日 还信用卡` | 本年内下一个 12-05 09:00 |
| `2026年12月5日 还信用卡` | 显式年份原样使用，年份整体消费 |
| `9:30 晨会` | 今天 09:30，已过则明天 |
| `交周报` | 默认 1 小时后 |
| `明天9点 交周报 #工作` | 同时归入「工作」分组 |

解析约束：

1. 「2小时后」这类时长描述不得被误判为钟点；
2. 「上周六」等过去时间不做推断，整段保留在标题中；
3. 不存在的日期（如 2 月 30 日）不消费、不静默夹到月末。

## 5 界面与交互

1. **主窗口**：左侧导航（视图：今天 / 逾期 / 全部 / 已完成；分组二级筛选；主题切换、设置入口），右侧自绘任务列表；
2. **列表**：分组标题吸顶并显示组内数量；行内标签展示分组、提醒形态、重复规则；置顶行带底色与 ★；逾期时间用赭色底胶囊；
3. **行操作**：点击左侧圆圈直接完成；双击进入编辑；右键菜单置顶 / 编辑 / 删除；选中行支持 Delete 删除、Enter 编辑；
4. **空态**：列表为空时显示引导页与快捷键提示；
5. **编辑窗**：内容 / 时间 / 重复 / 提醒方式四段式，全部自绘控件；底部操作栏固定可见（保存 / 取消 + 键入提示），内容超出工作区时内容区滚动、按钮不被推出视野；
6. **第三方弹窗禁用**：确认、提示、数字输入一律使用自绘卡片对话框，不使用系统 MessageBox / NumericUpDown；
7. **主题**：浅色 / 深色两套，侧栏底部一键切换，系统标题栏跟随深色；
8. **DPI**：所有尺寸与字号按屏幕 DPI 等比缩放，高 DPI 下不得出现裁切、遮挡、按钮出界。

## 6 系统集成

| 能力 | 规则 |
| ---- | ---- |
| 开机自启 | 写 HKCU Run 键，参数 `--startup`（静默启动，不弹主窗）；默认关闭 |
| 单实例 | 命名互斥量；重复启动广播消息唤起已有实例主窗口 |
| 全局快捷键 | `Ctrl+Alt+N`；被占用时提示一次，不阻塞启动 |
| 托盘 | 左键双击打开主窗；右键菜单：打开 / 新建任务 / 暂停全部提醒 / 退出；关闭主窗仅隐藏到托盘 |

## 7 数据与日志

| 内容 | 位置 |
| ---- | ---- |
| 任务数据 | `%APPDATA%\XiaoDing\tasks.json` |
| 应用设置 | `%APPDATA%\XiaoDing\settings.json` |
| 遮罩背景图 | `%APPDATA%\XiaoDing\overlay.png` |
| 日志 | `%APPDATA%\XiaoDing\logs\xiaoding-YYYYMMDD.log` |

1. 写入采用「临时文件 + 替换」，不得产生半截文件；
2. 任务文件损坏时隔离为 `.corrupt-时间戳.json` 并回退为空列表，不得直接丢弃；
3. 反序列化缺字段的任务需补默认值；`DueUtc` 缺省（0001-01-01）矫正为 1 小时后，避免被当成千年逾期立即误弹；
4. 日志按天分文件、单文件上限 1 MB、保留 7 天，只记事件名，不写任务内容。

---

## 8 非功能与验收要点

1. 单文件产物 ≤ 200 KB；Windows 10 1803+ 免装运行时直接运行；
2. 启动到主窗可用的时间 ≤ 1 秒；空载 CPU 趋近 0；
3. 时间解析与重复规则须有可复跑的自动化测试（`Code\tests`）；
4. 高 DPI（125%–200%）与最小窗口尺寸下，主窗、编辑窗、提醒卡片、遮罩均不得出现内容裁切或按钮不可达；
5. 深浅主题下所有文字对比度满足可读性要求（正文 ≥ 4.5:1）。
