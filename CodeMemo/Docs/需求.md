# CodeMemo 命令速查库 软件需求规格说明书（SRS）

## 文档基本信息

| 项目 | 内容 |
| --- | --- |
| 工具名称 | CodeMemo 本地命令速查库 |
| 版本 | v1.0 |
| 技术栈 | C# / WPF / .NET 8 / HandyControl 3.5.1 |
| 数据存储 | 本地 JSON（%AppData%\CodeMemo\commands.json） |

## 1 总体概述

### 1.1 产品定位

个人本地命令速查字典：分类收藏常用 PowerShell / Git 命令，支持备注、搜索过滤与一键复制。**不做命令执行**——很多命令带参数变量，聚焦"查阅 → 复制 → 去终端执行"的路径体验最好。

### 1.2 核心约束

- 技术栈强制 .NET 8 + HandyControl，HC 无对应组件时才允许 WPF 原生控件。
- v1 只做 PowerShell / Git 两大分类，Docker / Azure CLI 暂不做。
- 单机单用户，无需登录与联网。

### 1.3 术语定义

| 术语 | 含义 |
| --- | --- |
| 大分类 | 顶层分类，v1 固定为 PowerShell、Git |
| 子分组 | 大分类下的二级分组，如 Git → 分支操作 |
| 条目 | 一条命令记录：标题 + 命令全文 + 备注 + 分类归属 + 使用统计 |
| 占位符 | 命令中需替换的参数，统一用成对英文尖括号标注，如 `<branch-name>` |

## 2 分类与数据

### 2.1 分类结构

两级分类：大分类 → 子分组。v1 预置分组：

- **PowerShell**：文件与目录、文本与内容、进程与服务、网络诊断、系统信息、压缩与归档、脚本与安全
- **Git**：配置与初始化、基础操作、分支操作、合并与变基、撤销回退、远程仓库、查看历史、标签、暂存 stash、实用技巧

分类与子分组定义在代码 `Catalog` 中维护；用户新增条目时可输入预置之外的新子分组。
自定义子分组会追加显示在分类树对应大分类下（排在预置分组之后，按名称排序），并保证**任一节点的条目数恒等于其子节点条目数之和**；手工改库产生的空分组 / 空分类条目落到「（未分组）」「（未分类）」兜底节点，不会从树里消失。

### 2.2 条目字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 标题 | 是 | 一句话说清命令用途 |
| 命令 | 是 | 命令全文，占位符用 `<xxx>` 标注；多步命令可换行 |
| 备注 | 否 | 用途说明、适用场景、避坑提示 |
| 大分类 | 是 | 固定二选一 |
| 子分组 | 是 | 可从候选选择或输入新分组 |
| 使用次数 / 最近复制时间 | 自动 | 每次复制自动累加 / 更新 |
| 创建 / 更新时间 | 自动 | 审计用 |

### 2.3 内置命令库（种子数据）

- 首次启动（用户数据文件不存在）时自动导入内置命令库：PowerShell 38 条、Git 51 条，均带用途与避坑备注。
- 导入后以用户数据文件为准，用户在 UI 上的增删改**不会**被后续版本升级覆盖。

## 3 主界面

### 3.1 布局

固定三栏：

| 栏位 | 内容 |
| --- | --- |
| 左栏 | 分类树：全部命令（根）→ 大分类 → 子分组，节点带条目数角标，大分类默认展开、子分组默认收起；自定义子分组与兜底节点都会出现在树里，用户手动折叠/展开的选择在增删改后保留。底部固定「外观 / 常驻」偏好区（主题、字号、托盘常驻、全局热键） |
| 中栏 | 顶部快捷复制 Top10 面板（用过的命令才会出现，点一下即复制，可在「常用 / 最近使用」间切换）；下方命令列表：标题 + 命令单行截断 + 分类·分组角标 + 使用次数，命中搜索词的片段高亮；列表虚拟化，空结果显示空态提示与「新增命令」入口，行内"复制"按钮 |
| 右栏 | 详情：标题、分类分组、命令全文（等宽字体、可选中）、参数填充与复制预览、备注、复制次数 / 最近复制时间、"复制填好的命令 / 复制命令 / 编辑 / 删除"按钮 |

未选中条目时右栏显示空态提示。

### 3.2 搜索与排序

- 顶部全局搜索框：实时过滤，匹配范围 = 标题 + 命令全文 + 备注；多关键词空白分隔 AND 组合；忽略大小写。
- **有搜索词时忽略左侧分类限定，跨库显示匹配结果**；清空后恢复分类过滤。
- 命中的关键词在列表的标题与命令行里高亮标出（相邻/重叠命中合并为一段）。
- 排序下拉：默认顺序（按分类/分组定义顺序）/ 最近使用 / 使用最多。

### 3.3 快捷键

| 快捷键 | 行为 |
| --- | --- |
| `Ctrl + F` | 聚焦顶部搜索框并全选已有内容 |
| `Ctrl + N` | 打开「新增命令」编辑窗口 |
| `Ctrl + Alt + C` | 全局热键（可关闭）：任何程序前台时呼出本窗口并聚焦搜索框 |
| `Enter` / 双击行 | 复制当前选中的命令 |
| `Delete` | 删除当前选中的命令（需二次确认；焦点在输入框时仅删字） |
| `Esc` | 清空搜索框（搜索态下） |

### 3.4 快捷复制面板

- 只收录**真正复制过**的条目，最多 10 条；「常用」按使用次数降序（同次数比最近使用），「最近使用」按最近复制时间降序。
- 点面板里的胶囊即复制并累计使用次数；面板为空（一次都没复制过）时整块隐藏。

### 3.5 外观与常驻

| 项 | 说明 |
| --- | --- |
| 主题 | 明亮 / 暗色 / 跟随系统三选一（HandyControl SkinType.Default / Dark），切换**即时生效**；跟随系统时读注册表的 AppsUseLightTheme，并监听系统设置变化自动重切 |
| 字号 | 小 / 标准 / 大三档，界面字号资源整体缩放，切换即时生效 |
| 关闭时收进托盘 | 默认开启：关闭窗口只隐藏到托盘，避免误关打断「常驻」用法；从托盘菜单「退出 CodeMemo」才真正结束进程 |
| 全局热键 | 默认 `Ctrl+Alt+C`。左栏列出预设组合**胶囊（点一下即设置）**，也可以点「录制」后直接按一组键（Esc 取消），还可以在下方的**自定义输入框**里手输 / 粘贴写法（回车或点「应用」生效）；录制或输入的组合会补进胶囊列表 |
| 热键冲突处理 | 启动时注册失败 → 自动关掉该偏好并提示；用户新选／录制的组合被占用 → **回退到原来那个仍在生效的热键**并提示，不让人两头落空 |
| 托盘菜单 | 显示 / 隐藏窗口、打开数据目录、退出 CodeMemo；双击托盘图标在显示与隐藏间切换 |

偏好改动即时写入 `settings.json`；托盘图标取不到应用图标时退回 HandyControl 默认图标，不影响启动。
热键录制只接受「修饰键 + 主键」（A-Z、0-9、F1-F24、Space），纯修饰键会继续等待，写法统一规范成 `Ctrl+Alt+Shift+Win` 顺序。

## 4 条目操作

| 操作 | 行为 |
| --- | --- |
| 复制 | 列表行内复制按钮、详情页复制按钮或快捷面板胶囊：命令全文写入剪贴板，Growl 轻提示，使用次数 +1 并落盘（快捷面板因此会重新排序） |
| 参数填充复制 | 详情页把命令中的 `<xxx>` 列成输入框并实时预览，「复制填好的命令」把已填参数替换后复制；留空的占位符原样保留 |
| 新增 | 工具栏「新增命令」（或 `Ctrl+N`、空态里的按钮）打开编辑窗口；默认带入当前选中的大分类 / 子分组 |
| 编辑 | 详情页"编辑"打开编辑窗口回填原值 |
| 删除 | 详情页或列表操作后二次确认，确认后删除并落盘 |

编辑窗口校验：标题、命令、大分类、子分组必填；不满足时提示且窗口不关闭。

## 5 数据持久化

- 命令库：`%AppData%\CodeMemo\commands.json`；用户偏好：同目录 `settings.json`；「数据目录」按钮可直接在资源管理器里打开。
- 原子写：临时文件 + 替换，任意变更实时落盘。
- 写盘节流：复制只累计使用统计并登记改动，静默 1.5 秒后整库写一次（避免高频复制反复重写整库）；新增 / 编辑 / 删除、导入、窗口关闭这些关键时刻立刻落盘，**导入备份前必须先落盘**，保证备份里是最近统计。
- 可读格式：缩进 + 中文与尖括号不转义（`JavaScriptEncoder.UnsafeRelaxedJsonEscaping`），文件看得懂、能手改、能进 diff。
- 损坏隔离：命令库文件损坏时按空库启动并弹窗提示，**原损坏文件保留不覆盖**，用户可手工抢救；偏好文件损坏时静默回落默认值（偏好不值得打断启动）。
- 版本护栏：文件里的 `SchemaVersion` 高于当前程序支持版本时只提示、不擅自改写；缺少版本号时按当前版本加载并提示。
- 偏好归一化：主题 / 字号 / 热键取值非法时按默认值处理，保证配置文件被改坏也能启动。
- 导入：选择文件后先问导入方式（合并 / 整体替换 / 取消，取消返回 null）。
  - **合并去重**：现有条目在前，新增按导入顺序追加；内容指纹相同（分类 / 分组 / 标题忽略大小写与首尾空白，命令忽略首尾空白与换行差异、区分大小写）视为重复并跳过；同 Id 视为同一条命令，只更新标题 / 命令 / 备注 / 分类 / 分组，**保留本机使用统计与创建时间**。
  - **整体替换**：用导入内容覆盖现有库（老行为）。
  - 两种方式都会逐条校验（标题 / 命令 / 大分类 / 子分组必填，Id 缺失或重复自动重新分配），不合规条目跳过并在提示里给出条数与原因（合并会额外给出新增 / 更新 / 跳过重复的条数）；全部不合规时保持原数据不变。替换前自动备份为 `commands.yyyyMMdd-HHmmss.bak`（按时间保留最近 5 份）。
- 导出：另存为 JSON（含全部条目与使用统计），用于备份与换机迁移。

## 6 质量要求

- 单元测试覆盖（151 个用例）：种子数据合法性（必填字段、分类分组合法、Id/标题唯一、占位符成对）、分类树构建（自定义分组进树、父子计数一致、展开态保留）、占位符解析与填充、搜索过滤与排序、关键词高亮切分、常用/最近榜单、全局热键手势解析与键盘录制、写盘节流（合并写、立即落盘、丢弃待写）、合并去重（内容指纹、同 Id 更新且保留统计）、JSON 存取往返 / 可读中文 / 损坏隔离 / 版本护栏 / 备份轮转、偏好读写与归一化、导入校验、ViewModel（选中保留、空态、复制记账与节流、快捷面板、外观与常驻偏好、热键候选 / 录制 / 自定义输入 / 冲突回退、导入合并 / 替换 / 取消 / 备份前落盘）。
- 外观皮肤在 STA 线程里真加载资源字典验证：明亮 / 暗色 / 未知取值三态下的区域画刷与正文画刷、字号资源数值、**同进程内反复切换都生效**；跟随系统用假的系统状态源验证「系统亮→明亮、系统暗→暗色、切回固定主题后系统变化不再影响外观」，并断言监听随主题开启 / 停止。
- ViewModel 不直接调用剪贴板、对话框、外壳、外观与全局热键，全部依赖注入（`IClipboardService` / `IDialogService` / `IShellService` / `IAppearanceService` / `IGlobalHotkey`，打包为 `AppPlatform`），因此可脱离 UI 单测。
- Release 配置发布 win-x64 免安装单文件 EXE。
