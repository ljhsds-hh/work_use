# CodeMemo 本地命令速查库

分类收藏常用 PowerShell / Git 命令的个人速查字典：**分类浏览、备注避坑、全局搜索、一键复制**。不做命令执行——查阅后复制，去终端执行。

## 功能特性

- **两级分类树**：全部命令（根）→ PowerShell / Git → 子分组，节点带条目数角标；**你自己输入的新子分组也会出现在树里**（预置分组在前，自定义分组按名称排在后面），父节点计数恒等于子节点计数之和
- **内置命令库**：首次启动自动导入 89 条常用命令（PowerShell 38 + Git 51），每条带用途说明与避坑备注，开箱即用；导入后以你的数据为准，升级不覆盖
- **搜索过滤 + 关键词高亮**：标题 / 命令内容 / 备注 全文匹配，多关键词 AND 组合，有搜索词时跨分类全库搜索，命中片段在列表里高亮标出；无结果时给出空态提示与「新增命令」入口
- **一键复制**：行内或详情页复制到剪贴板，轻提示反馈，自动记录使用次数与最近复制时间，支持按“最近使用 / 使用最多”排序；**使用统计节流落盘**（复制不会每次都重写整库，退出 / 导入前会强制落盘）
- **快捷复制 Top10**：中栏顶部的胶囊面板列出常用（或最近使用）前 10 条，点一下就复制，不用先搜索再选中
- **参数占位符填充**：命令中需替换的参数统一用 `<尖括号>` 标注，详情页会自动把它们变成输入框并实时预览，**「复制填好的命令」一步带走**（留空的占位符原样保留）
- **暗色主题与字号**：左栏底部可切「明亮 / 暗色 / 跟随系统」皮肤与三档字号，**即时生效**并记进 `settings.json`；跟随系统时系统切亮暗会自动跟着换
- **托盘常驻 + 全局热键**：关闭窗口只收进托盘（可在左栏关掉），`Ctrl+Alt+C`（可换）随时呼出窗口并聚焦搜索；左栏有预设组合胶囊、可以点「录制」直接按一组键、也可以手输写法（回车即生效）；组合被其他程序占用时自动保留原热键并提示；托盘菜单可显示 / 隐藏 / 退出 / 打开数据目录
- **键盘流**：`Ctrl+F` 搜索、`Ctrl+N` 新增、`Enter` 或双击行复制、`Delete` 删除、`Esc` 清空搜索
- **增删改**：随时录入自己积累的命令，新子分组可直接输入创建；删除有二次确认
- **导入导出**：JSON 备份与迁移；导入时可选**整体替换**或**合并去重**（重复的按内容指纹跳过，同 Id 只更新描述、保留本机使用统计），逐条校验并跳过不合规条目（给出原因），替换前按时间戳备份原数据（保留最近 5 份）
- **数据目录**：一键在资源管理器里打开数据文件、备份与 `settings.json` 所在目录

## 界面

三栏布局：左分类树 + 外观/常驻偏好 / 中快捷复制面板 + 命令列表（空结果有空态引导） / 右详情（命令全文 + 参数填充与复制预览 + 备注 + 使用统计）。

## 构建与运行

依赖 .NET 8 SDK：

```bash
dotnet build Code/code-memo.slnx
dotnet run --project Code/src/CodeMemo/CodeMemo.csproj
```

发布免安装单文件 EXE：

```bash
dotnet publish Code/src/CodeMemo/CodeMemo.csproj -c Release
```

运行测试（151 个用例：种子合法性 / 分类树与计数 / 占位符 / 搜索排序与高亮 / 榜单 / 热键手势与录制 / 存储 / 写盘节流 / 合并去重 / 偏好 / 外观皮肤与跟随系统 / 导入校验 / ViewModel）：

```bash
dotnet test Code/code-memo.slnx
```

## 数据存储

- 命令库：`%AppData%\CodeMemo\commands.json`，任何变更实时落盘（原子写），**中文与尖括号不转义**，可读、可手改、可进 diff
- 用户偏好：`%AppData%\CodeMemo\settings.json`（主题含跟随系统、字号、托盘常驻、全局热键），文件坏了自动回落默认值，不影响启动
- 文件损坏时按空库启动并保留原文件待抢救，并提示抢救路径；文件版本高于当前程序时只提示不擅自改写
- 导入前自动备份为 `commands.yyyyMMdd-HHmmss.bak`（按时间保留最近 5 份）；备份前会先把待写的使用统计落盘，保证备份是最新的
