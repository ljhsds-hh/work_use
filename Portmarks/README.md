# Portmarks · 浏览器收藏夹迁移工具

在本机的 Edge / Chrome 之间按**原树结构**无损迁移/复制收藏夹。不用装扩展，不用导出复杂 HTML，选两个下拉框点一下即可完成同步。支持导出为专用的 .portmarks 文件进行跨机器搬运。

> 详细规范与说明：[docs/使用说明.md](docs/使用说明.md) · [docs/spec.md](docs/spec.md) · [CONTRIBUTING.md](CONTRIBUTING.md)。

## 功能特性

- **原树结构迁移**：同名文件夹自动合并，同层级书签自动追加末尾，层级与相对顺序无损保留。
- **纯本地、零联网**：仅监听 127.0.0.1 本地服务，绝不上传任何书签或个人数据；不碰历史记录、Cookie、密码与扩展。
- **只读源、安全写入**：源浏览器只读；目标浏览器写入前**强制校验进程退出状态**，并**自动生成时间戳备份**（Bookmarks.pmbak-...），采用临时文件重命名实现原子写入。
- **跨机器搬运**：支持导出专用的 .portmarks JSON 格式文件，并在任意机器的目标浏览器中预览差异后导入。
- **高颜值自绘 UI**：7 套淡雅主题色（雾蓝、鼠尾草、藕粉、杏桃、薰衣草、青瓷、沙金），支持深色/浅色/跟随系统模式，可自定义毛玻璃背景图并自动压缩防爆存。
- **全量单元测试覆盖**：涵盖合并规则、GUID 骨架常量校验、原子写入、格式往返与 HTML DOM ID 一致性检查等 34 项自动化测试。

## 快速使用

双击根目录下的 **start.cmd** 即可启动。程序会自动在默认浏览器打开操作界面，关闭命令行窗口即彻底退出程序。

## 技术栈

- 运行环境：Node.js 18+ (原生 ESM)
- 服务端：Node.js 原生 http 模块（零外部 npm 依赖）
- 前端：原生 JavaScript (ES Modules) + 语义化 HTML5 + CSS 变量设计系统
- 测试：Node.js 内置测试运行器 (
ode --test)
