# QuietRemind 任务提醒工具

常驻系统托盘的 Windows 桌面任务提醒小工具：设定任务与循环规则，**到点弹出全屏遮罩 + 居中提醒卡片**；重点解决"到点前关机/重启导致提醒错过"的办公场景——**关机前拦截提醒 + 开机后立即补提醒**，提醒必达。整个软件只做"提醒我有任务"这一件事，轻量克制，无声音、无广告、不联网。

## 运行

运行 `Code\publish\QuietRemind.exe`（自包含单文件，无需安装 .NET 运行时）。首次启动需解压，约 10–20 秒，之后启动很快。

首次运行自动注册计划任务（开机自启 + 进程守护，可设置关闭），程序常驻托盘。

## 功能

### 界面

- 企业级 Atelier 视觉系统：暖纸画布 + 墨色文字 + 深松绿主色 + 琥珀时间强调，深色导航栏与自绘标题栏
- **浅色 / 深色双模式 + 6 套主题色**（松绿、墨蓝、赭陶、紫檀、石墨、莓果），设置区即时切换、无需重启；深色配色单独校准对比度，连提醒卡片与编辑窗一起跟随
- 左侧导航 + 任务工作区 + 可收起设置检查器；今日概览、空状态、行内图标操作、统一焦点与悬停反馈
- 编辑/历史/快速新增/关机拦截均为同款无边框窗口；提醒浮层保持主屏全屏、逐条收尾

### 任务管理

- 任务字段：内容、提醒时刻（时:分）、循环规则、开始/结束日期、重复间隔、启用开关
- 五种循环规则：**单次**（指定日期）、**每天**、**每周**（勾选星期，含"工作日"一键预设）、**每月**（1~31 日，遇小月取月末）、**每年**（指定月/日，2 月 29 日平年取 2 月 28 日）
- **间隔**：每 N 天 / 每 N 周 / 每 N 个月（以开始日期为锚点）；**结束日期**含当天，留空长期有效
- 编辑保存后**新设置立即生效**（当天按新时刻触发，即使此前已触发过一次）
- 列表醒目展示待处理计数与下次提醒时刻；删除保留历史记录并支持 **5 秒撤销**；停用即不再提醒
- **历史记录**：每个任务可只读查看最近 200 条实例（计划/状态/处理时间/推迟说明）
- **快速新增**：Ctrl+Alt+N 呼出轻量新增窗（内容 + 时刻 + 单次/每天），默认开启、可关闭

### 到点提醒

- 秒级轮询，到点弹出**主屏全屏遮罩 + 居中提醒卡片**（置顶、左侧品牌条、浮入动效）
- **遮罩背景可自定义**：上传图片（可选模糊）+ 暗化程度可调
- 多条任务同时到期合并展示，逐条收尾：**完成 / 稍后再提醒（5/10/30 分钟可配置）/ 跳过**
- **提醒预览**：设置区一键以同样全屏样式预览，可随时关闭、不写入数据
- **提前提醒**（默认关闭）：到点前 N 分钟托盘气泡预告，不改变全屏提醒形态
- 全程无声音、无花瓣类装饰动画

### 运行诊断与数据备份

- 设置区"运行状态"按需展示计划任务注册/降级/上次运行结果、日志目录与最近落盘错误，可刷新、修复守护、打开日志（不进入秒级轮询）
- 数据备份：任务 + 实例 + 设置导出为单一 JSON；导入前自动备份当前数据并重启生效；启动时每日快照保留 5 份

### 关机前拦截提醒（核心）

- 关机/重启/注销时，若存在**今天还欠着**的任务，弹出拦截窗口逐条列出，提供【取消关机】与【仍要关机】
- 无欠账任务时静默放行，绝不无理由拖延关机
- 选【仍要关机】后，这些任务开机时立即补提醒

### 错过判定与开机补提醒

- 开机启动、睡眠唤醒、每次轮询三个时机扫描"计划时刻已过但未处理"的实例
- 确实错过的实例在下次开机/唤醒时**立即弹出补提醒**，条目标注"已错过"徽标
- 提醒弹出本身不改变状态：即使提醒窗口已弹出后程序被误杀，下次启动依然补提醒，无状态死角

### 进程守护

- 首次运行自动注册计划任务 `QuietRemind`：登录自启动 + 每 5 分钟守护触发
- 进程被误退/误杀后最迟 5 分钟自动拉起；重复启动自动合并为单实例
- 托盘【立即退出】需二次确认（明示守护失效影响），本开机周期内不再拉起，重启电脑后自动恢复

### 轻量与数据

- 常驻后台轻量：秒级轮询纯内存比较，空载内存参考 ≤100MB，无后台线程、无联网、无广告
- 数据存于 `%AppData%\QuietRemind\`（JSON 原子写入）；日志存于 `D:\logs\QuietRemind\`（按日分文件，保留 30 天，可完整回溯"为什么没提醒到"）

## 技术栈

- C# / .NET 8 / WPF
- UI：HandyControl 组件库 + Atelier 设计系统（`Themes/DesignTokens.xaml` 统一令牌与控件模板）
- 架构：标准 MVVM 分层，服务层零 UI 依赖、时钟可注入，核心逻辑完整单元测试
- 守护：Task Scheduler Managed Wrapper 注册计划任务
- 发布：单文件自包含 EXE（win-x64，开启压缩）
