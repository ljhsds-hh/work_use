# QuietRemind 任务提醒工具

常驻系统托盘的 Windows 桌面任务提醒小工具：设定任务与循环规则，**到点全屏强提醒**；重点解决"到点前关机/重启导致提醒错过"的办公场景——**关机前拦截提醒 + 开机后立即补提醒**，提醒必达。整个软件只做"提醒我有任务"这一件事，轻量克制，无声音、无广告、不联网。

## 运行

运行 `Code\publish\QuietRemind.exe`（自包含单文件，无需安装 .NET 运行时）。首次启动需解压，约 10–20 秒，之后启动很快。

首次运行自动注册计划任务（开机自启 + 进程守护，可设置关闭），程序常驻托盘。

## 功能

### 任务管理

- 任务字段：内容、提醒时刻（时:分）、循环规则、启用开关
- 四种循环规则：**单次**（指定日期）、**每天**、**每周**（勾选星期，如周一~周五）、**每月**（1~31 日，遇小月取月末）
- 列表醒目区分今日待提醒任务；新增/编辑/删除（二次确认）；编辑不影响已收尾历史；停用即不再提醒

### 到点提醒

- 秒级轮询，到点弹出**全屏遮罩强提醒窗口**（置顶、居中卡片、弹入动效）
- 多条任务同时到期合并展示，逐条收尾：**完成 / 稍后再提醒（5/10/30 分钟可配置）/ 跳过**
- 全程无声音、无花瓣类装饰动画

### 关机前拦截提醒（核心）

- 关机/重启/注销时，若存在**今天还欠着**的任务，弹出拦截窗口逐条列出，提供【取消关机】与【仍要关机】
- 无欠账任务时静默放行，绝不无理由拖延关机
- 选【仍要关机】后，这些任务开机时立即补提醒

### 错过判定与开机补提醒

- 开机启动、睡眠唤醒、每次轮询三个时机扫描"计划时刻已过但未处理"的实例
- 确实错过的实例在下次开机/唤醒时**立即弹出补提醒**，条目标注"已错过"徽标
- 提醒弹出本身不改变状态：即使提醒窗口已弹出后程序被误杀，下次启动依然补提醒，无状态死角

### 进程守护

- 首次运行自动注册计划任务 `QuietRemind`：登录自启动 + 每 5 分钟守护触发
- 进程被误退/误杀后最迟 5 分钟自动拉起；重复启动自动合并为单实例
- 托盘【立即退出】需二次确认（明示守护失效影响），本开机周期内不再拉起，重启电脑后自动恢复

### 轻量与数据

- 常驻后台轻量：秒级轮询纯内存比较，空载内存参考 ≤100MB，无后台线程、无联网、无广告
- 数据存于 `%AppData%\QuietRemind\`（JSON 原子写入）；日志存于 `D:\logs\QuietRemind\`（按日分文件，保留 30 天，可完整回溯"为什么没提醒到"）

## 技术栈

- C# / .NET 8 / WPF
- UI：HandyControl 组件库（HC 未覆盖处退用 WPF 原生，如全屏提醒窗、托盘）
- 架构：标准 MVVM 分层，服务层零 UI 依赖、时钟可注入，核心逻辑完整单元测试
- 守护：Task Scheduler Managed Wrapper 注册计划任务
- 发布：单文件自包含 EXE（win-x64，开启压缩）

## 构建与测试

```bash
dotnet build Code/quiet-remind.slnx
dotnet test Code/quiet-remind.slnx
dotnet publish Code/src/QuietRemind -c Release    # 输出单文件 EXE 到 publish 目录
```

## 测试

39 个 xUnit 单元测试全部通过：

- `OccurrencePlannerTests`：四种循环生成（含每月 31 日遇小月/闰年取月末）、滚动补缺、编辑重建不碰历史、当天已过时刻不追溯
- `ReminderEngineTests`：到点触发、运行期豁免不误判、启动/唤醒/时钟跳变错过扫描、稍后再提醒回退与再触发、强杀重启补提醒、收尾终态、停用过滤
- `ShutdownInterceptTests`：关机欠账判定矩阵（今天/明天/停用/已收尾/snooze）
- `JsonStoreTests`：序列化往返、原子写、损坏恢复备份
