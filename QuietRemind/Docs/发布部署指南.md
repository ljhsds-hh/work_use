# QuietRemind 发布部署指南

## 一、构建要求

- 环境：Windows 10/11，已安装 .NET 8 SDK（开发机需 8.0.x）
- 仓库结构：`QuietRemind/Code/`（解决方案 + 源码 + 测试）

## 二、开发构建与测试

```bash
cd QuietRemind/Code
dotnet restore quiet-remind.slnx
dotnet build quiet-remind.slnx          # Debug 构建，0 警告目标
dotnet test quiet-remind.slnx           # 39 个单元测试
```

## 三、Release 单文件发布

发布参数已在 `src/QuietRemind/QuietRemind.csproj` 中固化（Release 配置生效）：

- `RuntimeIdentifier=win-x64`、`SelfContained=true`、`PublishSingleFile=true`
- `IncludeNativeLibrariesForSelfExtract=true`、`EnableCompressionInSingleFile=true`（体积约减半）
- `SatelliteResourceLanguages=zh-Hans;en`（精简语言资源）

```bash
dotnet publish src/QuietRemind -c Release
```

产物：`src/QuietRemind/bin/Release/net8.0-windows/win-x64/publish/QuietRemind.exe`
（自包含单文件，免安装 .NET 运行时，体积约 60MB 级）

> 发布脚本会同时生成运行所需的全部程序集（HC/TaskScheduler/NotifyIcon 均打包进单文件）。如需 Windows Defender 豁免，仅需对 exe 单独配置。

## 四、运行与部署

1. 将 `QuietRemind.exe` 复制到目标机任意目录（如 `D:\Tools\QuietRemind\`），双击运行
2. 首次运行自动完成：
   - 注册计划任务 `QuietRemind`（登录自启 + 每 5 分钟守护，可用 `schtasks /query /tn QuietRemind` 验证）
   - 创建数据目录 `%AppData%\QuietRemind\` 与日志目录 `D:\logs\QuietRemind\`
3. 程序常驻系统托盘；关闭主窗口不退出，从托盘右键【立即退出】退出

### 卸载/停用

- 打开主界面 → 设置区 → 关闭「开机自启动与进程守护」→ 计划任务被注销，不再自启与守护
- 手动清理残留：`schtasks /delete /tn QuietRemind /f`；删除 `%AppData%\QuietRemind\`（数据）；日志目录可自行清理

## 五、发布到 GitHub Release

仓库惯例（参照 create-tpl）：

1. 打标签：`git tag -a v1.0.0 -m "v1.0.0"`
2. 推送标签并创建 Release，附件上传 `QuietRemind.exe`
3. 在 `QuietRemind/README.md` 顶部「运行」节更新 Release 下载链接
