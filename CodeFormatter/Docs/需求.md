# Forge · 代码锻造 软件需求规格说明书（SRS）

## 文档基本信息

| 项目 | 内容 |
| --- | --- |
| 工具名称 | Forge · 代码锻造（离线代码格式化器） |
| 版本 | v1.0 |
| 技术栈 | 单文件 HTML / CSS / 原生 JavaScript（零依赖、零构建） |
| 运行环境 | 现代浏览器（Edge / Chrome 等）本地打开，无需服务器 |

## 1 总体概述

### 1.1 产品定位

本地离线的代码格式化 / 压缩小工具：把别处复制来的乱代码（网页查看源码、日志里抠出来的 SQL、压缩后的配置等）粘贴进来，一键格式化成可读排版，或反向压缩成单行，双栏对照后复制走。**不做工程级 IDE**——没有文件树、没有保存工程、没有语法检查，聚焦"粘贴 → 转换 → 复制"这一条路径。

### 1.2 核心约束

- **单文件交付**：全部代码在一个 `CodeFormatter.html` 里，双击即用，无安装、无构建、无外部依赖文件。
- **完全离线**：代码内容只在本机浏览器内处理，不上传；唯一可选联网点是用户自填的背景图片 URL。
- **转换不解释**：工具只做排版与压缩，不做语法校验、不重构、不改语义（已知限制见第 6 章）。

### 1.3 术语定义

| 术语 | 含义 |
| --- | --- |
| 引擎 | 某一种语言的格式化 + 压缩实现，注册在 `engines` 表中，按语言 key 取用 |
| 自动识别 | 对输入文本按各语言特征关键字打分，取最高分且不低于阈值的语言 |
| 主子句 | SQL 中独立换行的大子句（SELECT / FROM / WHERE / 各类 JOIN 等） |
| ASI 保护 | JS 压缩时对「行首不可省略分号」场景保留换行，避免合并行改变语义 |

## 2 语言支持与引擎

### 2.1 语言总表

| 语言 | 格式化缩进 | 说明 |
| --- | --- | --- |
| JSON | 2 空格 | 直接走浏览器 `JSON.parse` / `JSON.stringify`，非法输入报「JSON 解析失败：…」原文 |
| XML | 2 空格 | 与 XAML / HTML 共用 XML 家族解析器 |
| XAML | 4 空格 | 同上，仅缩进宽度不同（贴合 WPF 手写习惯） |
| HTML | 2 空格 | 同上并叠加 HTML 特例（void 元素、raw 元素、IE 条件注释） |
| CSS | 2 空格 | 先剥离注释再重排；属性 `prop: value;` 归一 |
| JavaScript | 4 空格 | K&R 花括号、`} else {` 合行、正则字面量按上下文消歧 |
| SQL | 2 空格 | 主子句换行、关键字统一大写（仅识别集合内的关键字） |
| C# | 4 空格 | K&R；支持 `@"..."` 逐字串、`$"..."` 插值串、`#region` 等预处理指令 |
| Java | 4 空格 | 与 C# 共用大括号语言排版器 |

### 2.2 XML 家族（XML / XAML / HTML）规则

- 标签属性统一序列化为**双引号**（源里是单引号也会归一），布尔属性保留无值形式。
- **只有纯文本内容的元素收为一行**：`<a>文字</a>` 不拆三行；文本含空行的（段落间距语义）不收。
- HTML void 元素（`br` / `img` / `input` 等 14 种）不增加缩进深度，也不自动补 `/`；`script` / `style` / `textarea` / `pre` 四种 raw 元素**内容原样保留不重排**。
- 注释、`<![CDATA[...]]>`、`<?xml ... ?>`、`<!DOCTYPE ...>` 各自独立成行原样保留。
- 压缩：去注释（HTML 的 IE 条件注释 `<!--[if ...]>` 保留）、文本空白折叠、结构完整保留；raw 内容原样不动。

### 2.3 CSS 规则

- 格式化**先剥离全部 `/* */` 注释**再重排（有意为之，见第 6 章已知限制）。
- 选择器 `{` 前保留空格；声明冒号后归一为单空格（含 `--var` 自定义属性）；`url(...)` 内部的分号不会被误判为声明结束。
- `@media` / `@supports` / `@keyframes` 等嵌套 at-rule 内层再缩进。
- 压缩：安全去空白（选择器组合符、`:after` 之类不被压坏），字符串字面量原样保留，行尾分号与 `}` 之间的 `;` 去掉，`@charset` 后保证一个空格。
- 最后一条声明若源码没写分号，格式化后保持没分号（不补）。

### 2.4 JavaScript 规则

- K&R 花括号，`} else {` / `} catch {` 合行；4 空格缩进；`for (` / `while (` 括号前留空格（JS 引擎既定风格，与 C#/Java 引擎的 `if(` 风格不同，各自一致）。
- **正则字面量按上下文消歧**：前一个非空白 token 是运算符或 `return` / `typeof` / `new` 等关键字时按正则处理，否则按除法（紧跟 `)` 之后的正则会按除法处理，见已知限制）。
- 模板字符串 `` `...${...}` `` 整体保留（含嵌套模板与内插中的字符串）。
- 注释独立成行跟随缩进；单行块注释可留在行尾。
- **属性冒号 `{a: 1}` 贴身**（冒号后留空格）：向前扫描——先遇 `,` / `}` 且不在未闭合三元里判为属性冒号，先遇 `;` / `)` / 裸 `:` 判为三元；`case 1:` / `default:` 标签冒号同样贴身（该行无 `?` 时）。
- 压缩带 **ASI 保护**：`return` / `throw` / `break` / `continue` / `yield` 行尾、`++` / `--` 前缀、`)` `]` 后直接跟 `(` 或标识符等场景**保留换行**，其余换行压成空格或删除；`a + +b` / `a - -b` 之间保证空格不被合并成 `++`。

### 2.5 SQL 规则

- 主子句（SELECT / FROM / WHERE / HAVING / GROUP BY / ORDER BY / LIMIT / OFFSET / UNION [ALL] / 各类 JOIN / INSERT INTO / VALUES / UPDATE / SET / DELETE FROM / CREATE TABLE 等）各自独立成行；SELECT 与主子句后的内容缩进一级。
- 顶层逗号处换行（SELECT 列表逐列一行）；括号内不因逗号换行。
- 识别集合内的关键字统一大写（集合外的标识符保持原样，函数名不大写）。
- 字符串 / 反引号标识符原样保留（含 `''` 转义写法）；`--` 行注释与 `/* */` 块注释格式化时独立成行保留，压缩时丢弃。

### 2.6 C# / Java 规则

- K&R 花括号，`} else {` / `} catch (…) {` 合行，`} while (...)` 合行，`});` 等收尾链与 `}` 同行；4 空格缩进。
- C# 专属：`@"..."` 逐字字符串（`""` 转义）、`$"..."` 插值字符串（含 `{}` 内嵌表达式与花括号计数）、`//` 与 `/* */` 注释、`#region` 等预处理指令整行保留。
- **复合运算符合并**：`==` / `!=` / `<=` / `>=` / `&&` / `||` / `+=` / `-=` / `*=` / `/=` / `%=` / `&=` / `|=` / `^=` / `<<=` / `>>=` / `??=` / `=>` / `->` / `::` / `?.` / `??` / 位移等两侧加空格成对输出，不拆散（`++` / `--` 按前后文作后缀贴身、前缀留空格）。
- **泛型实参表**：`<` 向前扫描到配对 `>` 才算泛型（`List<int>` / `Dictionary<string, List<int>>` / `List<?>` 均不加空格；前有无空格均可，`public <T> T M()` 的类型参数表同样成立），扫描不到配对则按比较符加空格；泛型内 `,` 归一为 `, `，`?`（可空）贴身。
- **可空类型 `?`**：`?` 贴在类型后且向前扫描先遇 `;` `{` `}` 而非 `:` 时判为可空标记贴身输出（`int? x` / `a?[0]`）；先遇 `:` 则按三元运算符加空格。
- 一元符号：`!` / `~` 与前面无操作数的 `+` / `-` / `*` / `&` 按前缀贴身输出（`a = -b`、`if(!x)`、`var p = &x`）；后缀 `++` / `--` 贴身（`i++`）。
- `case 1:` / `default:` 标签冒号贴身并在冒号后留一个空格；`for (…; …; …)` 括号内的分号不拆行、分号后留一个空格；Java 注解 `@Xxx(...)` 独立成行。

### 2.7 自动识别

- 按特征关键字加权打分：JSON（首尾大括号 + 键值对形态）、XAML（`x:Class` / `xmlns:x` / `{Binding`）、HTML（DOCTYPE 与常见标签）、XML（`<?xml` 声明与自闭合形态）、SQL（SELECT/FROM/WHERE 等词频）、C#（`using System` / `namespace` / `var x = new`）、Java（`package` / `import java.` / `public static void main`）、CSS（选择器 + 属性形态）、JS（`const` / `=>` / `console.log`）。
- 取最高分且**总分 ≥ 3** 才判定；XAML / HTML 优先于 XML 判定（避免普通 XML 被误认成 HTML）。
- 识别失败提示「未识别，请从下拉框选择语言」，不猜；手动选择语言后不再自动识别。

## 3 界面与交互

### 3.1 布局

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 品牌（Forge · 代码锻造）+ 语言下拉（含「自动识别」）+ 格式化 / 压缩 + 粘贴 / 复制输出 / 清除 + 主题切换 / 背景设置 |
| 状态栏 | 圆点 + 一句话反馈（识别结果、成功字符数、失败原因），`role="status"` 可被读屏播报 |
| 主区 | 左「源码」栏 ⇄ 中轴（操作时脉冲动画）⇄ 右「成品」栏（只读）；每栏带行号槽与行高亮层 |

### 3.2 编辑器行为

- 行号随内容增减实时更新，与正文**滚动同步**；当前聚焦行高亮、选区跨行合并高亮（渲染走 `requestAnimationFrame` 合帧）。
- 输入变化 200 ms 防抖后刷新自动识别结果（仅在「自动识别」模式下）。

### 3.3 快捷键

| 快捷键 | 行为 |
| --- | --- |
| `Ctrl + Enter` | 格式化 |
| `Ctrl + Shift + M` | 压缩 |
| `Ctrl + Shift + L` | 清除（输入输出与语言选择一并复位） |
| `Ctrl + Shift + D` | 切换深浅主题 |
| `Esc` | 关闭背景设置面板 |

### 3.4 状态反馈

| 场景 | 反馈 |
| --- | --- |
| 输入为空点格式化 | 「输入为空，请先粘贴或输入代码。」（警告色） |
| 自动识别成功 | 「已识别：〈语言名〉」 |
| 格式化 / 压缩成功 | 「已格式化：〈语言名〉（N 字符）」，中轴脉冲动画 |
| 引擎抛错 | 「格式化失败：〈原因〉」，输出清空 |
| 复制失败 | 提示手动选中后 Ctrl+C，不静默失败 |

## 4 主题与背景

### 4.1 深浅主题

- 深色为默认基调（黄铜色 accent），浅色成套重定义全部设计令牌（`[data-theme]` 切换，无散落硬编码色值参与逻辑）。
- 首次打开跟随 `prefers-color-scheme`；手动切换后持久化到 `localStorage` 的 `forge-theme`；处于「跟随系统」状态时系统亮暗变化自动跟随。

### 4.2 自定义背景

| 参数 | 范围 | 说明 |
| --- | --- | --- |
| 颜色 | 取色器 | 纯色背景 |
| 图片 | 本地文件 / URL 链接 | 链接优先于本地图；本地图读为 dataURL，超过 1920px 自动等比缩小并按 JPEG（质量 0.82，仍超限降到 0.65）重压后存储 |
| 透明度 | 0–100% | 背景层整体透明度 |
| 玻璃 | 0–100% | 内容面板毛玻璃 scrim 深度（保证代码可读性） |
| 模糊 | 0–40px | 背景图模糊半径 |

- 开启后整页透出背景，顶栏 / 状态栏 / 面板改为半透明 + 毛玻璃，代码文字加描边光晕保持可读。
- 配置持久化到 `localStorage` 的 `forge-bg`；所有取值读取时归一化到合法范围，配置损坏按默认值处理，不影响启动。
- 面板支持 Esc 与点击外部关闭；「移除」一键清掉背景图。

## 5 数据与隐私

- **代码内容零出域**：不联网、不上报、无遥测；断网全功能可用（自填背景图 URL 除外）。
- 本地存储仅两个键：`forge-theme`（主题）、`forge-bg`（背景配置 JSON）。不含代码内容。
- 剪贴板：优先 `navigator.clipboard`，不可用自动降级 `execCommand("copy")`；读取（粘贴按钮）失败提示手动 Ctrl+V。

## 6 质量要求与已知限制

### 6.1 验证方式

- 引擎层冒烟测试：`node Code/scripts/smoke-formatter.js`，36 条断言覆盖九种语言的格式化 / 压缩 / 自动识别关键行为（含 C#/Java 复合运算符、泛型、可空类型、括号内分号等修复回归）；脚本**直接从 HTML 里切出真实引擎代码**执行，杜绝脚本与页面两份代码漂移。
- 页面同时暴露 `window.__fmt`（detectLanguage / engines / 主题与背景函数），可在浏览器控制台手工抽查。
- 界面观感（主题、背景、行高亮）需浏览器人工过一遍。

### 6.2 已知限制（如实记录）

| 编号 | 限制 | 说明 |
| --- | --- | --- |
| K-3 | JS 正则字面量紧跟 `)` 之后被当除法：`if(a)/re/.test(b)` → `if (a) / re /.test(b)` | `/` 在 `)` 后存在除法歧义；若改为「`)` 后允许正则」，`(a+b)/c/d` 这类除法链会被误判成 `/c/d` 正则，等于按下葫芦浮起瓢，v1.0 选择保持现状。规避：把正则先赋给变量再用 |
| K-4 | CSS 格式化与压缩丢弃全部 `/* */` 注释 | 重排前整体剥离注释，属有意设计；需保留注释的场景请留在源文件 |
| K-5 | HTML 压缩去注释（IE 条件注释除外）、SQL 压缩去注释 | 压缩语义本就是去注释 |

> K-1（C#/Java 复合运算符拆散）与 K-2（泛型被当比较符）已于本轮修复并纳入回归断言（2026-09-22）。K-3 是词法歧义，当前行为是权衡后的选择，不算未修的 bug。

## 7 发布

单文件即产物：`Code/CodeFormatter.html` 本身就是发布物，拷走即可用；无版本化安装包。修改后跑一遍冒烟脚本 + 浏览器人工过一遍界面即可发布。
