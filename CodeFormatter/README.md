# Forge · 代码锻造（离线代码格式化器）

打开浏览器就能用的**单文件离线代码格式化 / 压缩工具**：粘贴代码 → 自动识别语言 → 格式化或压缩 → 双栏对照复制走。零安装、零构建、零依赖，代码全程不出浏览器。

> 需求基线：[Docs/需求.md](Docs/需求.md)。

## 功能特性

- **九种语言**：HTML / JavaScript / CSS / XAML / XML / SQL / C# / Java / JSON，每种都有独立的格式化与压缩引擎
- **自动识别**：默认按关键字打分识别语言（XAML 优先于 XML、HTML 优先于 XML 等），识别不出再从下拉框手选；输入变化时实时刷新识别结果
- **格式化 / 压缩一键切换**：格式化统一缩进与排版，压缩去掉注释与多余空白（JS 压缩带 ASI 保护，不会把 `return` 后面的换行吞掉导致语义改变）
- **双栏对照**：左源码、右成品，中轴动画反馈；两栏都有行号、当前行高亮与选区行高亮，滚动同步
- **深浅主题**：深色 / 浅色一键切换，首次打开跟随系统，手动选择后记住；跟随系统时系统切换亮暗会自动跟着换
- **自定义背景**：纯色 / 本地图片 / 图片链接（链接优先于本地图），可调透明度、玻璃模糊强度、背景模糊半径；本地大图自动压到 1920px 再存，避免撑爆 localStorage
- **剪贴板按钮**：粘贴 / 复制输出一键完成，旧浏览器自动降级为 `select + execCommand`；读不了剪贴板时提示手动 Ctrl+V，不会卡死
- **快捷键**：`Ctrl+Enter` 格式化、`Ctrl+Shift+M` 压缩、`Ctrl+Shift+L` 清除、`Ctrl+Shift+D` 切主题
- **状态栏实时反馈**：识别结果、成功与失败原因（如「JSON 解析失败：…」）都在底部状态栏说清楚

## 使用方法

直接双击 [Code/CodeFormatter.html](Code/CodeFormatter.html) 用现代浏览器（Edge / Chrome 等）打开即可。没有构建步骤，没有服务器，没有任何依赖文件——就这一个 HTML。

可选：把页面固定到浏览器新标签页或做成桌面快捷方式，当成本地小工具用。

## 数据与隐私

| 项 | 说明 |
| --- | --- |
| 代码内容 | **只在你本机的浏览器里处理，绝不上传**；断网照样能用 |
| 本地存储 | 仅两个键：`forge-theme`（主题选择）、`forge-bg`（背景配置），清理浏览器数据即一并清掉 |
| 联网点 | 唯一可选联网点是「背景 → 链接」填了远程图片 URL 时浏览器去加载那张图；不填就完全离线 |

## 已知限制（实测，2026-09-22）

如实记录，不藏着：

| 限制 | 具体表现 |
| --- | --- |
| JS 正则紧跟 `)` 之后被当除法 | `if(a)/re/.test(b)` 格式化后变成 `if (a) / re /.test(b)`（此处 `/` 有除法歧义，引擎按除法处理；规避：把正则先赋给变量再用） |
| CSS 注释不保留 | 格式化与压缩都会删掉全部 `/* */` 注释（有意为之，想要注释请留在源文件） |
| 压缩后注释一律丢弃 | XML / HTML 压缩去注释（IE 条件注释除外），SQL 压缩去注释 |

> C#/Java 复合运算符拆散（`==` → `= =`）与泛型被当比较符（`List<int>` → `List < int >`）两处历史缺陷已修复（2026-09-22），并纳入回归断言。

复跑证据：

```bash
node Code/scripts/smoke-formatter.js
```

（36 条断言覆盖九种语言的格式化 / 压缩 / 自动识别关键行为，含上述修复的回归；脚本直接从 HTML 里切出真实引擎代码来跑，不会出现脚本与页面两份代码漂移。）
