# create-tpl 发布部署指南

## 1. 前置条件

| 项目 | 要求 |
| --- | --- |
| 开发/打包机 | 已安装 .NET SDK（本工程使用 .NET 10 SDK 编译，目标框架固定为 net8.0-windows） |
| 网络还原 | 首次构建需联网还原 HandyControl NuGet 包 |
| 目标运行机 | 任意 Windows x64 设备，**无需安装任何运行库** |

## 2. 一键打包命令

在 `Code/` 目录执行：

```bash
dotnet publish src/CreateTpl -c Release
```

发布参数已固化在 `CreateTpl.csproj`（Release 配置生效）：

| 参数 | 值 | 说明 |
| --- | --- | --- |
| PublishSingleFile | true | 单文件打包 |
| SelfContained | true | 自包含 .NET 8 运行时，目标机免安装 |
| RuntimeIdentifier | win-x64 | 64 位 Windows |
| EnableCompressionInSingleFile | true | 单文件内压缩，体积约减半 |
| IncludeNativeLibrariesForSelfExtract | true | 原生库一并嵌入 |

如需自定义输出目录，可追加 `-o <输出路径>`。

## 3. 产物位置

```
Code/src/CreateTpl/bin/Release/net8.0-windows/win-x64/publish/
└── CreateTpl.exe    （单文件，约 64 MB，双击即可运行）
```

## 4. 分发方式

- 直接拷贝 `CreateTpl.exe` 到任意 Windows x64 设备双击运行；
- 无需安装、无需配置、无注册表写入；程序仅在用户指定的根目录下创建文件，卸载即删除 EXE 本体。

## 5. 常见问题

| 现象 | 处理 |
| --- | --- |
| 双击无反应/被杀毒拦截 | 单文件自解压可能触发误报，将 EXE 加入白名单 |
| 目标目录创建失败提示权限不足 | 检查目标盘写权限，或以管理员身份运行 |
| 需要生成 32 位版本 | 将 csproj 中 `RuntimeIdentifier` 改为 `win-x86` 后重新发布 |
