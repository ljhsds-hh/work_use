create-tpl 项目模板快速生成工具 需求说明书

## 1. 项目简介

create-tpl 是一款轻量化自定义项目模板快速生成小工具，专为个人开发项目标准化初始化设计。工具核心作用为：根据用户输入的**工程根目录**和**工程名称**（支持单个或批量多个工程名），自动一键创建标准化固定工程目录结构及配套空白文档，无需手动新建文件夹、创建文件，统一所有个人项目的初始化模板规范，提升新项目创建效率。

本工具为前置辅助工具，用于统一后续所有开发项目的初始目录结构，保证工程规范统一、整洁统一。

## 2. 技术规范

- **开发框架**：Microsoft .NET 8（固定版本，不允许使用其他版本）
- **程序类型**：WPF 桌面应用
- **UI组件强制规范**：全程优先使用 HandyControl 组件库实现所有界面元素、布局、弹窗、输入控件；仅当 HandyControl 无对应功能组件时，才可使用 WPF 原生控件
- **UI要求**：界面简洁美观、布局规整、适配窗口大小，采用 HandyControl 原生主题风格，视觉统一干净
- **编码规范**：采用标准 MVVM 分层架构，代码简洁、逻辑清晰，关键步骤添加注释，适配后续自主迭代扩展
- **运行方式**：编译为.NET8独立单文件EXE，无需额外安装运行库，双击即可直接运行

## 3. 核心功能需求

### 3.1 交互式参数输入

程序启动后，通过HandyControl搭建的可视化界面，引导用户输入两项核心参数，并做完整合法性校验，摒弃控制台交互方式：

- 输入1：**工程根目录路径**（如：D:/Projects/），校验路径是否合法、是否存在，路径不存在则自动创建根目录
- 输入2：**工程名称**（自定义英文/中文项目名，作为二级根文件夹名称），支持多行输入，一行一个工程名，即批量创建模式（详见 3.6）

参数输入错误、路径非法、空名称时，给出中文友好提示，支持重新输入，不直接闪退崩溃。

### 3.2 自动创建标准化工程目录结构

根据用户输入的根目录+工程名，自动生成完整固定模板目录、空白文件，最终生成的工程结构严格如下，不增删、不修改层级：

```Plain
工程根目录/工程名
├── CLAUDE.md    （空白文件预置指定说明文本）
├── README.md    （纯空白文件，无内容）
├─Code/          （空文件夹，用于存放项目源码）
└─Docs/          
   └─需求.md     （纯空白文档，用于存放项目需求文档）
```

### 3.3 文件内容规范

- **README.md**：完全空白，无任何字符、无注释、无换行
- **Docs/需求.md**：完全空白，无任何字符、无注释、无换行
- **CLAUDE.md**：自动写入固定说明文本，文本含义为标注该文件为工程AI关键记忆文件，用于留存项目关键信息，供AI迭代开发使用，标准文案： **此处为工程关键记忆文件，请记录项目核心需求、开发规范、关键逻辑等关键信息，供AI迭代开发、上下文复用使用**

### 3.4 容错与防重复机制

- 判断目标工程文件夹是否已存在，避免重复创建、覆盖已有文件
- 若文件夹已存在，给出中文提示：“当前工程已存在，无需重复创建”，并跳过该工程（批量模式下不中断其余工程的创建，详见 3.6）
- 路径权限不足、文件夹创建失败等异常捕获，给出友好中文报错，程序不闪退

### 3.5 执行反馈

- 所有目录、文件创建完成后，界面展示**创建成功提示**，并展示完整的工程生成路径
- 界面可视化展示生成的目录结构预览，让用户直观确认创建结果
- 支持直接关闭程序退出，或继续创建下一批项目模板

### 3.6 批量创建模式

工程名称支持一次输入多个（多行文本，一行一个工程名），共用同一工程根目录，批量生成多个标准化工程：

- **输入规则**：多行输入，每行一个工程名；自动忽略空行，并去除每行首尾空格；重复输入的工程名自动去重
- **校验规则**：逐个工程名独立校验合法性，任一工程名非法时整体提示，不开始生成；单个工程文件夹已存在时跳过该工程并提示，不中断其余工程的创建
- **执行顺序**：按输入顺序逐个创建，每个工程独立执行 3.2 目录创建与 3.3 文件内容规范
- **单点失败隔离**：批量执行中任一工程因任何原因创建失败（已存在、权限不足、磁盘异常等），仅记录该工程的失败原因并跳过，不影响、不中断后续工程的继续创建
- **结果反馈**：完成后汇总展示各工程创建结果（成功 / 已存在跳过 / 失败及原因）；若存在未成功创建的工程，须以醒目方式明确列出**未完成的工程清单及失败原因**，提醒用户哪些工程没有生成，便于针对性补建或处理

## 4. 非功能需求

- 轻量化：程序无多余依赖、无冗余功能，启动极速
- 稳定性：全程异常捕获，非法输入、路径错误、权限问题均不会导致程序崩溃
- 规范性：严格固定模板结构，所有生成的项目结构完全统一，无自定义偏差
- 可移植：支持发布为.NET8独立单文件EXE，任意Windows设备可直接运行

## 5. 交付要求

AI需输出完整可编译的.NET8 WPF项目源码，包含：

1. 完整的项目工程文件、配置文件
2. 基于MVVM架构、HandyControl实现的完整UI界面、参数校验、目录创建、文件生成全套逻辑代码
3. 完善的代码注释、异常处理逻辑
4. 单文件独立部署打包步骤

## 6. 功能范围

本次实现：自定义根目录+工程名输入（单个或批量多行）、标准化固定目录结构创建、CLAUDE.md预置文本、空白文件生成、重复校验、异常容错、执行结果反馈、批量创建模式。不扩展自定义模板、多模板切换等额外功能。
